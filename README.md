# 🎬 Parents VS Enfants — La Veillée

Jeu télévisé de veillée pour centre de loisirs : un mur de 40 cartes mystère,
deux équipes (Enfants VS Parents), blind tests, mimes, questions diaboliques
avec triche, bonus/malus… projeté au vidéoprojecteur et pilotable depuis un
téléphone.

- **`index.html`** — l'écran de jeu (à projeter)
- **`telecommande.html`** — la télécommande pour le téléphone du présentateur
- **`cartes.js`** — tout le contenu des cartes (à personnaliser !)
- **[GUIDE.md](GUIDE.md)** — le mode d'emploi complet du présentateur
